# Official scorer and B5 audit, 2026-11-14

## Method and result

`cargo run --release -p bb_stats --example scorer_audit -- 300` simulates seeds 0–299,
compares the prior `classify_bip` diagnostic with the new scorer's ruling from the
serialized game log, and checks the team proof, PA and hit-component identities for each
team in every game. It uses two workers. These are scorer judgments over simulated facts,
not 397 independently hand-reviewed video clips.

| Measure | Result |
|---|---:|
| Prior provisional fielder's choices | 397 |
| Those now scored as hits | 14 (3.5%) |
| Prior provisional hits now scored as choices | 65 |
| Unresolved rulings | 0 |
| AB / H / HR / K / SF | 21,196 / 6,637 / 1,268 / 3,533 / 170 |
| Batting average, H / AB | .3131 |
| BABIP, (H − HR) / (AB − K − HR + SF) | .3241 |

All 14 converted choices were first handled by an infielder. The old diagnostic denied a
hit for *any* other runner put out after an infielder secured the ball. Under
[2026 OBR 9.05(b)(1), (3), (4)](https://www.baseball.ca/uploads/files/2026%20Rules/2026%20MLB%20Official%20Rules%20-%20EN.pdf),
a force and an infielder's putout on the runner's one-base advance or return deny the hit;
a tag on an extra-base attempt need not. Failed attempts on a preceding runner are judged
against the reference throw to first, accounting for choices the old diagnostic called
hits. First glove handling is retained separately from first secure possession, so a
deflection is not erased.

The scorer uses the actual first-base touch and an average, set, noise-free throw from the
first secure possession, in the actual atmosphere. Throws out of range on the fly continue through a noise-free bounce; those that never
reach the bag have a negative-infinite margin. An explicit flag distinguishes missing timing from zero. Throw
records distinguish a play on a runner from a routine return; carrying the ball for an out
is also recorded. A batter's goal at a throw is used as a **provisional** proxy for whether
an extra base was taken on that throw; a full counterfactual of the batter's subsequent
running is not available. The simulation has no error rulings, so the scorer does not
invent them. Sacrifice flies and RBI follow rules-spec §10.4–10.5 under that no-error model.
Older logs lacking the evidence can produce an explicit undetermined ruling. So can a
walk-off stopped before the batter's first-base touch; the scorer does not fabricate that
touch or assert a hit in its absence. The current sacrifice-fly territory boundary is a
configurable 45 m radial approximation, rather than a park-specific outfield boundary.

## Gameplay and log comparison

The new fields, `BattedBallRuling`, and recorded advance causes change the serialized log
and therefore its digests. No agent reads these facts. For seeds 0, 1, 7 and 42, the complete
sequence of pitch records, rules events and original rules facts was compared byte-for-byte
as debug text with the starting commit `db5c012`; all matched. Scores were 7–2, 4–7, 6–13
and 12–7 respectively. Captions use the log-backed ruling and name the base of a runner
put out on a choice. The comparison program is `sim/crates/bb_game/examples/a12_gameplay_compare.rs`.
